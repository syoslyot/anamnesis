# Anamnesis (`am`)

Research workflow memory for AI agents. Manages hypotheses and experiments stored in `.anamnesis/`.

Subcommands: `hyp` | `exp` | `run` | `done` | `find`

Refer to the Claude Code skill definition for full behaviour specification.
The file format, workflow, and auto-recording rules are identical across platforms.

Files are stored in `.anamnesis/hypotheses/` and `.anamnesis/experiments/` as markdown with YAML frontmatter.
